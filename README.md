# 弦上 FretFlow

面向零基础电吉他学习者的纯静态互动练习网站。与 B 站 UP 主「帅帅是把电吉他」的《零基础入门电吉他教学完整版》分集搭配使用。

## 功能

- 乐理知识：六线谱、简谱与五线谱、节奏、把位、和弦乐理、技巧符号，配互动图解与小测。
- 指板训练：标准调弦 0–12 品发声，第一、第二、第四、第五把位，C 大调音阶与找音挑战。
- 和弦工坊：开放和弦、五和弦指法与试听，60 秒计时切换训练。
- 曲谱跟练：小星星、青花瓷课程两句片段、天下简化和弦版，支持变速、循环、节拍器和谱下先备知识。
- 今日练习：本机计时、练习分钟、连续天数、挑战正确率与近七天 ECharts 图表。

不需要登录或后端。练习记录只保存在当前浏览器的 `localStorage`，清除浏览器数据会删除记录。

## 本地运行

```bash
npm install
npm run dev
```

终端会输出本地地址。默认是 `http://localhost:5173`，端口被占用时 Vite 会自动选择下一个端口。

## 检查与构建

```bash
npm run lint
npm run build
npm run preview
```

生产文件输出到 `dist/`。`vite.config.ts` 已设置 `base: './'`，可部署在域名子路径下。

## Gitee Pages

将 `dist/` 中的内容发布到 Gitee Pages 的静态站点根目录即可。Gitee 账号实名认证、Pages 权限与发布操作需要在账号所有者自己的 Gitee 后台完成，本项目不自动上传或发布。若暂时不使用 Pages，直接运行上面的本地预览命令即可。

## 内容与版权说明

- 视频仅提供 B 站分集外链，不搬运课程视频、音频或整套课件。
- 小星星按第五把位 C 调入门票整理；青花瓷按课程两句教学片段整理，不是全曲谱，细微连线节奏以视频示范为准。
