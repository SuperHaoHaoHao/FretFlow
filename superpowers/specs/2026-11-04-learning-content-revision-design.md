# FretFlow 零基础内容纠偏与练习重构设计

## 意图

保留现有视觉风格与静态架构，把网站从“看起来完整但内容未充分核验”改成适合零基础学习者长期翻阅、跟视频复习和每天练琴的可靠工具。核心是音高、八度、节奏、谱面版本都可追溯，互动服务于看、听、找、弹，不做书面问答题。

## 目标

- 乐理先给总归纳，再按主题查阅；明确区分音名、唱名、简谱、首调、固定调、把位和指型。
- 指板默认同时显示简谱数字与 do/re/mi/fa/sol/la/si，数字带准确八度点；点击仍可发声。
- 《小星星》与课程第五把位练习一致；《青花瓷》按用户截图补齐 16 小节及八度、节奏、歌词、延音线。
- 《天下》同页提供强力和弦伴奏与可核实的 Solo 学习内容，不再展示普通开放和弦冒充目标练习。
- 每个练习下方直接列出把位、和弦、技巧、速度和谱面来源。
- 保持纯静态、无登录、本机记录，兼容 GitHub Pages 子路径。

## 非目标与反目标

- 不制作原曲完整官方谱，不把第三方扒谱或网站改编标为官方版本。
- 不在公开证据不足时猜 Solo 音符，不拼接专辑版、2020 Live 版与 DJ 版。
- 不做问答题、选择题或理论考试；保留直接点指板的找音练习，但不加入书面理论考核。
- 不重做现有品牌与整体页面，不引入后端、账号或音频文件下载服务。
- 不要求初学者先学完全部乐理才能开始弹。

## 已选方案与取舍

采用“速查手册 + 跟练模式”，用户已在两种方案中明确选择。保留现有组件和视觉体系，新增乐理总览、统一简谱组件与来源标注。

另一方案是严格按视频课程顺序组织，因复习查找效率低、过度依赖单一博主而未采用。仅做逐字纠错也不采用，因为无法解决概念混杂、八度点缺失和练习用途不清的问题。

## 内容依据与版本边界

### 乐理

公开资料交叉核查采用 Fender 的六线谱/调弦/和弦教学、Open Music Theory 的音高节奏与三和弦、Guitar Pro 的简谱和技巧文档、Berklee 入门课程结构，以及用户课程截图。页面给每个主题附来源链接。

内容分为“共识事实”“常见记谱约定”“入门教学建议”，避免把口诀当定律。重点修正：

- 简谱是一种数字记谱法；首调/固定调是唱名体系，不是谱纸种类。
- 八度点上高下低；数字右侧附点属于节奏，位置不能混淆。
- 延音线连接相邻同音并合并时值，后音不重新发声；不同音之间的弧线通常是连音线。
- 强力和弦由根音和纯五度构成，可重复八度根音；没有三音，本身不分大小，不是三和弦的等价替代。

### 把位与指型

将两个概念分开：

- “左手第五把位”是 5–8 品，一品一指是入门定位法，《小星星》使用这里。
- 用户截图的“第五把位 Mi 指型”圆点实际在 12–15 品，是课程第五种指型标签，不能当作 5–8 品。

指板扩展到至少 15 品，新增“课程 Mi 指型”视图；不把原第五把位整体移动，以免破坏《小星星》。

### 青花瓷

唯一主基准为用户提供的 `W2-EX9 青花瓷` 截图：`/Users/lingfeng/文件/电吉他/PixPin_2026-11-04_16-10-34.png`，`1=C`、4/4、80 BPM、16 小节。公开简谱只用于交叉核对，不覆盖课程截图。逐小节转录已完成并保存在研究记录中，实施时直接按该截图复核，不需要重新推断旋律。

- 当前 8 小节片段替换为完整 16 小节课程旋律。
- 低音 5、低音 6 使用下点；不带点的 5 为一弦三品 G4。
- 第 7、8→9、15→16 小节延音线按截图录入，延续音只计时、不重新拨弦。
- 第 9 小节包含 1.5 拍事件。
- 每小节数据必须合计 4 拍；歌词按截图录入。截图“袖色渲”与通行歌词不同，保留截图并在备注说明，不静默改写。

### 天下

主版本为张杰《明天过后》专辑版相关和声骨架，4/4，参考 72 BPM。根据公开弹唱扒谱副歌 `F—G—Em—Am` 的变调夹四品关系，移高四品为 `A—B—G♯m—C♯m`，教学简化为：

`A5—B5—G♯5—C♯5`，每和弦一小节，四拍下拨起步。

页面明确写“副歌强力和弦入门改编，不是原曲电吉他分轨逐音扒谱”。新增 B5、G♯5、C♯5 手型和试听，删除该练习的普通开放和弦版本。

Solo 只使用能从公开附谱视频可靠辨认并标注版本的内容，优先短片段而非伪造完整 Solo。若无法可靠辨认，则提供分版本学习入口和“暂未核验逐音谱”的明确说明，不填充原创旋律冒充《天下》。DJ、2020 Live、专辑版绝不混用。

## 页面与组件改动

### 乐理知识

- 顶部增加“零基础乐理总图”：音高三层关系、全半音、六线谱坐标、节奏时值、和弦公式、强力和弦手型。
- 二级主题调整为：吉他坐标、音名与唱名、简谱与八度、节奏与休止、把位与指型、和弦与强力和弦、技巧符号。
- 删除 quiz 状态、题目组件与“30 秒小检查”。改为“马上试一下”的发声/定位互动和“这一页怎么用”。
- 增加长期速查区域，使用原生 `details` 收纳进阶解释，保证浏览器页内查找可用。
- 每章显示来源与适用边界；保留“已看懂”本机记录。

### 指板训练

- 新建统一 `JianpuNote` 显示模型：高点槽、数字、唱名、低点槽。八度点由 MIDI 推导，C4–B4 为课程中音区。
- 默认显示“简谱 + 唱名”；音名在详情区保留。变化音明确标为 C 大调外音，不硬编数字。
- 空弦准确显示：1→6 弦为 `3、低音7、低音5、低音2、倍低音6、倍低音3`。
- 音高范围扩展至 15 品，指板横向滚动；保留方向键 roving tabindex，并确保焦点进入可视区域。
- 删除“音名选择题”挑战，保留“在指板上找到某音”的直接操作练习；不再出现书面问答。

### 曲谱跟练

- 共用简谱组件显示数字、唱名、八度点、时值和歌词。
- 播放器支持 `fromPrev`：不重复发声但保持计时；循环、变速、节拍器保持可用。
- 谱下先备知识继续固定展示，并新增“版本与来源”。
- 《天下》改为“强力和弦伴奏 / Solo 片段”双轨切换；没有可靠 Solo 数据时第二个区域只显示版本导航，不显示伪造谱面。

### 和弦工坊

- 新增 B5、G♯5、C♯5，统一“强力和弦”命名，保留“五和弦 Power Chord”作为辅助解释。
- 《天下》入口卡改为实际 `A5—B5—G♯5—C♯5` 练习，不再宣传 Em—C—G—D。
- 强力和弦说明补充根音弦、可移动手型与无三音特性。

## 数据与实现约束

- 继续使用 Vite + React + TypeScript + 现有 CSS 和 Lucide，不为本次内容修订增加大型依赖。
- 曲谱事件显式保存简谱八度、唱名、弦品、拍数、歌词与连线；显示值尽量由同一 MIDI/弦品来源推导，避免音高与文字分叉。
- 不直接编辑 `dist`；部署产物仅在用户明确要求发布时更新。
- 项目没有既有测试体系，不新增测试脚手架。可用一次性只读脚本核对每小节拍数和弦品音高，但不留下测试文件。

## 验证

1. 内容复核：逐一核对 16 小节《青花瓷》均为 4 拍，八度点和实际弦品音高一致；检查空弦及 Mi 指型表。
2. 检查《天下》四个强力和弦构成音和指法，所有改编/来源文案与数据一致。
3. `npm run lint` 和 `npm run build` 必须通过。
4. 浏览器端到端：乐理无问答题、总览与 details 可检索；指板数字/唱名/八度点正确，点击发声；15 品与 Mi 指型可见；方向键不丢失焦点。
5. 三首曲谱实际播放、暂停、逐音点击、循环和变速；《青花瓷》延续音不重复发声；《天下》只出现强力和弦和经核验的 Solo 内容。
6. 桌面与手机布局、hash 路由、本机完成记录和既有和弦训练不回归。
