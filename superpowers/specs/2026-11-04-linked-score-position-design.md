# 曲谱与把位联动练习设计

## 目标

把曲谱练习重构为新手能直接照着弹的“把位图 + 紧凑六线谱”。桌面端把位图在左、谱面在右，手机端上下排列；当前音在两个视图中同步高亮。

## 已确认方案

- 使用语义化 HTML、CSS Grid 和现有 React / TypeScript，不引入谱面依赖，不使用 SVG 绘制交互音符。
- 六线谱的数字嵌入弦线，以谱纸底色遮住数字后的线段；按节拍分配宽度，按小节组织并紧凑换行。
- 保留简谱数字、do/re/mi/fa/sol/la/si、八度点、歌词、拍长、延音、休止、当前音、播放暂停、循环、节拍器和隐藏弦品功能。
- 把位图只显示当前曲子的把位，显示六条弦、品位和 C 大调音阶；点击音可发声，当前谱音同步定位。
- 手指形状统一为：圆形食指、方形中指、菱形无名指、三角形小拇指；由现有 `getFinger()` 按把位计算，并显示图例和当前音提示。
- 抽出可复用的把位图与六线谱组件，新曲子继续使用事件数据驱动。

## 非目标

不修改曲子的音符、节奏或和声内容；不增加登录、问答题或新曲；不提交、不推送、不发布。

## 验证

运行完整 lint 和生产构建；在浏览器检查《小星星》《青花瓷》的桌面与手机布局，验证点击音符、播放高亮、把位定位、手指形状、延音、隐藏弦品和键盘操作。
